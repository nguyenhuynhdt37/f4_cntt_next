Hệ thống Thư viện & Quản lý Tài liệu Khoa CNTT **F4**. Hỗ trợ tìm kiếm, đọc tài liệu PDF trực tuyến, nạp điểm và mượn sách.

---

## ✨ Tính Năng

- 📖 **Đọc PDF Trực Tuyến:** Trình đọc tài liệu PDF mượt mà ngay trên giao diện web.
- 👤 **Portal Sinh Viên:** Nạp điểm, quản lý tủ sách cá nhân.
- 🛠️ **Admin Portal:** Quản lý NXB, Tác giả, Thể loại tài liệu, Thống kê lượt đọc.

```bash
git clone https://github.com/nguyenhuynhdt37/f4_cntt_next.git
cd f4_cntt_next
npm install
npm run dev
```
